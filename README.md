# Play Ludo Game Online
# 🎲 Ludo Queen

A modern web-based implementation of the classic **Ludo** board game built using **HTML, CSS, JavaScript, and jQuery**. The game offers an interactive multiplayer experience with smooth animations, sound effects, and responsive gameplay directly in the browser.

---

## 🚀 Features

- 🎮 Play with **2, 3, or 4 players**
- 🎲 Animated dice rolling
- ♟️ Automatic and manual pawn movement
- 🛡️ Safe zones and capture mechanics
- 🏆 Win tracking and player ranking
- 🔊 Sound effects with toggle option
- 🔄 Restart game functionality
- 📱 Responsive design for desktop and tablet
- ⛶ Fullscreen mode support
- 🎨 Classic Ludo board with smooth UI animations

---

## 🛠️ Tech Stack

## ⚙️ Installation

1. Clone the repository

```bash

```

2. Navigate to the project folder

```bash
cd ludo-mania
```

3. Open `index.html` in your browser.

No additional dependencies or build tools are required.

---

## 🎮 How to Play

1. Select the number of players.
2. Click **Start** to begin the game.
3. Roll the dice during your turn.
4. Roll a **6** to bring a pawn onto the board.
5. Move your pawns according to the dice value.
6. Capture opponent pawns by landing on their position.
7. Move all four pawns to the home area to win.
